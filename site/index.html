macOS e Linux?

A roda, a integração com o Explorador e os documentos usam recursos do Windows. Versões para outros sistemas ainda não existem.

Instale em três passos

  1. Abra o arquivo baixado.

    Procure MediaConverter-2.5.0-Windows-x64-Setup.exe na pasta Downloads.

  2. Mantenha “Somente para mim”.

    É a opção padrão e não pede administrador. Escolha a pasta e avance.

  3. Ative a roda rápida.

    Abra o Media Converter → aba Roda rápida e ligue o menu do botão direito e o Enviar para. O atalho já vem ativo.

O Windows mostrou um aviso?

O instalador ainda não tem certificado de editor. Confira se baixou pelo botão deste site. O SmartScreen pode mostrar “Mais informações” e a opção para executar; políticas de uma organização podem impedir a instalação.

Perguntas frequentes

Antes de converter.

O arquivo original é alterado?

Nunca. A conversão grava uma cópia temporária e só dá o nome final quando termina inteira. Se você cancelar, a cópia incompleta é apagada.

Preciso do Microsoft Office?

Só para Word, Excel e PowerPoint, e para PDF → DOCX. Vídeo, áudio, imagem, PDF em imagens, Markdown, texto, dados, legendas e ZIP funcionam sem ele.

Converter melhora a qualidade?

Não. Converter para WAV, FLAC ou ProRes facilita a edição, mas não recupera detalhes que o arquivo de origem já perdeu.

Meus arquivos são enviados para algum lugar?

Não. Tudo roda no seu computador. O aplicativo não usa servidor de conversão.

A roda não abre com o atalho.

Outro programa pode estar usando Alt+Shift+C. Na aba Roda rápida, escolha outro atalho; o status mostra se ele foi registrado.
